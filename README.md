# 🛒 Online Shopping Cart

A full-stack e-commerce application built with **React**, **Vite**, **Spring Boot**, **Spring Data JPA**, **Spring Security**, **JWT**, and **PostgreSQL**.

The project is organized as a monorepo containing a modern React frontend and a RESTful Spring Boot backend.

## ✨ Features

- 🔐 User registration and authentication
- 🛡️ JWT-based authentication and authorization
- 👤 User management
- 📦 Product management
- 🛒 Shopping cart management
- 📋 Order management
- 🧾 Order items and cart items
- 🗄️ PostgreSQL database integration
- 🌐 RESTful backend APIs
- ⚛️ React + Vite frontend
- 🎨 Responsive frontend UI
- ⚡ Fast development with Vite
- 🧪 Backend test setup with Spring Boot
